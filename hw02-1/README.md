# HW02-1：股票收益与组合风险分析

## 数据来源与样本

- 数据来源：CSMAR 数据库“个股交易数据—日个股回报率文件”。
- 获取日期：2026-09-24。
- 原始覆盖期：2020-12-31 至 2026-09-16。
- 正式评价期：2021-01-04 至 2026-09-16。
- 数据文件：`data/十只股票.dta`。

样本包含 10 只 A 股股票：中兴通讯、美的集团、比亚迪、宁德时代、恒瑞医药、贵州茅台、长江电力、中国平安、工商银行、紫金矿业。股票覆盖通信、家电、汽车、电力设备、医药、食品饮料、公用事业、非银金融、银行和有色金属等行业。

## 运行说明

1. 进入 `hw02-1/` 目录。
2. 打开并从头运行 `hw02-1.ipynb`。
3. Notebook 使用相对路径读取 `data/十只股票.dta`。
4. 主要图表和表格会输出到 `results/`。

## 主要输出

- 个股不复权收盘价时序图。
- 个股累计净值图。
- 个股日收益率时序图。
- 20 日滚动年化波动率图。
- 个股收益率描述统计表。
- 收益率相关系数矩阵。
- 等权组合与市值加权组合累计净值、年化收益率、年化波动率和最大回撤。
