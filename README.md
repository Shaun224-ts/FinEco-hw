# FinEco-hw

本仓库用于提交金融经济学 HW02 的两道题。仓库内保留了本次分析使用的清洗后数据快照、Notebook、依赖说明和复现入口；运行时使用相对路径，不依赖本机桌面上的原始目录。

## 作业入口

- [HW02-1：股票收益与组合风险分析](./hw02-1/hw02-1.ipynb)
- [HW02-2：房地产公司财务特征分析](./hw02-2/hw02-2.ipynb)

## 数据与复现说明

两题数据均来自 CSMAR。由于原始下载文件体积较大，仓库中保留本次作业实际使用的清洗后数据快照；Notebook 中包含清洗口径、检查过程、统计表、图形和结果解释。

复现时分别进入 `hw02-1/` 和 `hw02-2/` 目录，从头运行对应 Notebook。图表和表格会输出到各题的 `results/` 文件夹。
