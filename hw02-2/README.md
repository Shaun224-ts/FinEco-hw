# HW02-2：房地产公司财务特征分析

## 数据来源与样本

- 数据来源：CSMAR 数据库，包含房地产上市公司基础信息、资产负债表、利润表和产权性质相关数据。
- 获取日期：2026-09-26。
- 分析期间：2005 年至 2015 年；部分 2004 年财务数据用于计算 2005 年的期初或平均分母。
- 数据文件：`data/合并后数据.dta`。

本题构建房地产 A 股上市公司的年度非平衡面板，重点比较公司数量、产权结构和财务特征变化。产权分为国有、民营和其他类别，报告中只做描述性比较，不把国有与民营差异解释为产权的因果作用。

## 运行说明

1. 进入 `hw02-2/` 目录。
2. 打开并从头运行 `hw02-2.ipynb`。
3. Notebook 使用相对路径读取 `data/合并后数据.dta`。
4. 主要图表和表格会输出到 `results/`。

## 主要输出

- 年度公司数量和样本处理说明表。
- 产权结构数量及占比图表。
- 六个财务指标的年度均值和中位数比较。
- 国有企业与民营企业的均值、中位数对比。
- 年度有效样本量表。
- 异常值检查表，用于判断指标突变是否可能来自离群值、异常分母、样本进出或产权变更。

## 依赖

见 `requirements.txt`。核心分析使用 Stata 完成，Notebook 用于呈现代码、输出和解释。
